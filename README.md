# Titanic Survival Prediction

A Machine Learning project that predicts whether a Titanic passenger
survived using the K-Nearest Neighbors (KNN) algorithm.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Process
1. Data Cleaning
2. Missing Value Handling
3. Feature Engineering
4. Train/Test Split
5. Feature Scaling
6. Hyperparameter Tuning with GridSearchCV
7. KNN Classification
8. Model Evaluation
9. Confusion Matrix

## Features
- Pclass
- Sex
- Age
- SibSp
- Parch
- Fare
- FamilySize
- IsAlone
- FareBin
- AgeBin

## Model
K-Nearest Neighbors (KNN)

## Evaluation
The model was evaluated using:
- Accuracy Score
- Confusion Matrix
